# 豆包电脑版接入

已在 Windows 豆包电脑版的“本地电脑”任务中实际验证 STDIO 和 MCP Apps；不同客户端版本的菜单可能不同。

## 推荐：直接上传便携 ZIP

1. 下载 `zhijian-resume-<版本>-doubao-win-x64.zip`，**不要解压**。
2. 豆包电脑版打开 **插件 · 技能 · 工作台 → 添加 → 上传插件**，拖入 ZIP 或选择文件。
3. 等待安装和下载完成，在管理页确认 `Zhijian Resume` 插件及 `zhijian-resume-desktop` 连接器已启用。早期手动添加的 `zhijian-resume` 可关闭，避免同时调用两套工具。
4. 新建工作任务，选择 **本地电脑**，发送：

```text
请用智简简历创建一份虚构的中文求职简历，并打开内嵌编辑器，让我修改内容、切换模板、调整行间距并导出分页 PDF。
```

包内包含官方 Node.js Windows x64 运行时，无需安装 Node、npm、Codex CLI，无需填写命令或路径。PDF 使用系统已有的 Edge / Chrome。0.4.0 实测豆包列表仍按技术标识显示 `Zhijian Resume` 与默认图标，忽略清单内的中文 displayName 和品牌图标。中文说明已显示；打开编辑器后可看到“智简简历”品牌。保留规范要求的 ASCII 标识，避免破坏升级与启动定位。

**安装仍需联网**：豆包会上传 ZIP 并重新下载到本机，插件仅自己可见。运行时不需要我们的公网服务或 ngrok；豆包对话及宿主界面仍可能联网。

如安装后显示运行失败，先在插件管理页刷新，等包下载完再对 `zhijian-resume-desktop` 点击“重新启动”。不要改成公网连接器。升级当前自定义上传插件时，可卸载旧插件再上传新版，草稿保存在插件目录之外，不会随插件包替换。

启动适配只读取豆包当前用户安装目录下的本插件清单，运行包内 Node；不修改系统 PATH、执行策略或其他插件。如果豆包未来更改安装目录布局，需要更新插件适配器。

## 备用：手动 STDIO 连接器

适用于开发调试或没有 ZIP 上传入口的客户端，需要自行安装 Node.js 22.13+。

1. 双击旧格式 Windows 安装包的 `install.cmd`，选择 `1`；无需安装 Codex CLI。
2. 打开 `%LOCALAPPDATA%\Programs\ZhijianResume\doubao-setup.txt`。如自定义安装目录，在该目录找这个文件。
3. 在豆包打开 **插件 · 技能 · 工作台 → 添加 → 新建自定义连接器**。
4. 填写：

| 字段 | 值 |
|---|---|
| 服务器名称 | `zhijian-resume` |
| 传输类型 | **STDIO** |
| 命令 | setup 文件中的 Node.exe 完整路径 |
| 参数 | setup 文件中的 cli.cjs 完整路径，作为**单独一项** |
| 环境变量 | 按 setup 文件添加 `CHROME_PATH` |

路径直接粘贴，不在输入框中额外套引号，不把 node 和参数合并成一条命令。不填写 URL、端口或 Header。

5. 保存，确认连接器开关已启用；新建工作任务，运行环境选择 **本地电脑**。
6. 发送：

> 请使用 zhijian-resume 的 create_resume 创建虚构演示简历：姓名“示例用户（虚构）”，个人总结“本地编辑器演示”，技能 React、TypeScript，simple 模板。请展示该工具的 MCP Apps 编辑器，不使用 docx-editor。

7. 卡片显示编辑器后，可点击“去右侧打开”，再用宿主“全屏显示”放大。修改内容、切换模板、调整行距；等保存完成后导出并下载 PDF。

不要仅凭豆包模型的文字判断 UI 是否成功：实测其工作区标签查询可能返回空列表，导致模型声称“界面未显示”，而编辑器实际已可交互。以可见界面和保存／下载结果为准。

若保存报 `MCP App structured context is too deep`，请安装 0.3.0 或更新版本，更新连接器参数后重新启用，并创建新卡片。当前版本已采用浅层参数，服务端仍执行完整文档校验。

## 本地运行边界

不启动 HTTP 服务，不需要公网域名或 ngrok。豆包启动本机 Node 子进程，编辑器 HTML 通过 MCP 资源交给宿主，草稿与 PDF 渲染保留本地。豆包模型对话及它自己的 MCP Apps 沙箱可能需要联网；本项目不宣称豆包完全离线。
